    Configuration

    Every SecurityConfig field with its type, default, and effect. The canonical field names are the snake_case python names (the cross-language interop surface, spec 02): the Kotlin properties are the camelCase forms, and adapters bind them idiomatically (Spring relaxed binding maps guard.redis-url to redisUrl; Ktor takes the builder or the Kotlin property names). Types and defaults are normative; a conformant build with default config behaves as the reference with default config.

    Generated by docs/tools/w8d_config_docs.py from ConfigFieldRegistry.kt (the ported reference field table) joined with the spec 02 field semantics. Re-run it whenever the registry or spec 02 changes; a field that exists in code but not here is a defect.

    Network / proxy

    Field Kotlin property Type Default Effect
    trusted_proxies trustedProxies str list (IP or CIDR; "unix" allowed) [] Peers trusted to set X-Forwarded-For. Entries are normalized to canonical IP/CIDR string form at validation. /0 entry logs a warning (spoof risk) but is accepted.
    trusted_proxy_depth trustedProxyDepth int 1 Number of proxies expected in the X-Forwarded-For chain. MUST be >= 1; 0 or negative rejected.
    trust_x_forwarded_proto trustXForwardedProto bool false When true, HTTPS detection consults X-Forwarded-Proto; otherwise only the URL scheme.
    whitelist whitelist str list (IP/CIDR) or none null Non-empty = restrictive: only listed IPs pass the global IP check. An explicit whitelist match overrides the blacklist; dynamic IP bans still apply. null (not empty) means "no whitelist".
    blacklist blacklist str list (IP/CIDR) [] Blocked IPs/CIDRs. Enforced ahead of country and cloud checks; overridden by an explicit whitelist match. Entries normalized to canonical form.
    ## Redis / distributed state
    Field Kotlin property Type Default Effect
    enable_redis enableRedis bool true Enables distributed state (shared bans, counters, caches). Requires the redis optional package; see Capability gating.
    redis_url redisUrl str or none "redis://localhost:6379" Connection URL.
    redis_prefix redisPrefix str "guard_core:" Prefix on every Redis key (section 08 key names embed it).
    redis_socket_connect_timeout redisSocketConnectTimeout float or none, > 0 (gt=0.0) 2.0 Seconds to wait for a TCP connection. MUST be > 0 (0 = non-blocking mode, not "no timeout"). null disables the timeout.
    redis_socket_timeout redisSocketTimeout float or none, > 0 (gt=0.0) 2.0 Seconds to wait per read/write. MUST be > 0. null = no timeout.
    redis_health_check_interval redisHealthCheckInterval int, >= 0 (ge=0) 30 Seconds between pooled-connection health checks; 0 disables.
    redis_max_connections redisMaxConnections int or none, >= 1 (ge=1) null Connection-pool cap; null = backend default.
    redis_retries redisRetries int, >= 0 (ge=0) 1 Retries with exponential backoff on transient connection/timeout errors before surfacing; 0 disables.
    redis_fail_open redisFailOpen bool false On Redis unavailability, skip the failing check and let the request through instead of honoring fail_secure. Default false: fail_secure governs every check failure including Redis outages.
    ## IP banning / penalties
    Field Kotlin property Type Default Effect
    enable_ip_banning enableIpBanning bool true Master switch for IP banning.
    auto_ban_threshold autoBanThreshold int, >= 1 (ge=1) 10 Suspicious-request count that triggers auto-ban.
    auto_ban_duration autoBanDuration int, >= 1 (ge=1) 3600 Auto-ban duration in seconds.
    threat_ban_config threatBanConfig map of category → {threshold: int >= 1, duration: int >= 1} {} Per-category overrides of auto_ban_threshold/auto_ban_duration. Valid categories: the penetration-detection categories (see enabled_detection_categories) plus the pseudo-category "rate_limit". Unknown category keys: rejected. Unlisted categories fall back to the flat thresholds.
    enable_rate_limit_auto_ban enableRateLimitAutoBan bool false Feed rate-limit violations into the auto-ban engine: each active-mode violation increments the "rate_limit" suspicious count and runs the same threshold logic (threat_ban_config["rate_limit"] first, then flat). Requires enable_ip_banning to actually ban.

    ## Cloud providers
    Field Kotlin property Type Default Effect
    block_cloud_providers blockCloudProviders str set or none null Providers to block. Valid names: AWS, GCP, Azure, DigitalOcean, Linode, Vultr. A bare name blocks the whole provider; "<name>:!<region>" blocks the provider except that region. Region data exists for AWS and GCP only; a carve-out on other providers exempts nothing. Unknown provider names: rejected.
    cloud_ip_refresh_interval cloudIpRefreshInterval int, 60–86400 (ge=60, le=86400) 3600 Seconds between cloud IP range refreshes.
    cloud_ip_store cloudIpStore store instance, store factory, or none null Override for the shared cloud-IP cache (section 01 surface). null = auto-construct the Redis-backed store when Redis is enabled. A factory is a callable taking the redis handler and returning a store (defers construction).
    lazy_init lazyInit bool true Defer cloud-IP HTTP fetches and geo MMDB downloads to a background task. Effective only when Redis is enabled AND the adapter wires the deferred-init startup hook; otherwise cloud/geo init happens on demand and this flag is inert. First requests may see partially populated ranges.

    ## Detection / penetration
    Field Kotlin property Type Default Effect
    enable_penetration_detection enablePenetrationDetection bool true Master switch.
    enabled_detection_categories enabledDetectionCategories str set all categories Subset of: xss, sqli, dir_traversal, path_traversal, cmd_injection, file_inclusion, ldap, xml, ssrf, nosql, file_upload, template, http_split, sensitive_file, cms_probing, recon, proto_pollution, code_injection, deserialization. Unknown names: rejected. Empty set while detection is on: warning (detection enabled but never matches).
    excluded_detection_headers excludedDetectionHeaders str set {} Headers exempted from the categories known to false-positive on their typical values (identity/proxy headers skip ssrf only); other categories still scan them. Merged with the hardcoded default exclusion set.
    excluded_detection_params excludedDetectionParams str set {} Query parameters excluded from detection scanning.
    excluded_detection_body_fields excludedDetectionBodyFields str set {} JSON body keys excluded from detection scanning, matched at any nesting depth; also applied to form-urlencoded and multipart text-part field names.
    detection_scan_body detectionScanBody bool true Scan the request body. False: detection restricted to path, query, headers; the body is never read.
    detection_max_body_inspect_bytes detectionMaxBodyInspectBytes int, 1024–10485760 (ge=1024, le=10485760) 262144 Max bytes read from the start of the request body for detection. Only this prefix is scanned; payloads beyond it, or split across the boundary, are not detected. Also bounds gzip-bomb decompression. Without a bounded body reader (section 01.2), the body is not read at all and detection falls back to path/query/headers; either way a one-time warning names the cap, the client, and which happened.
    detection_max_content_length detectionMaxContentLength int, 1000–100000 (ge=1000, le=100000) 10000 Budget for the semantic (ML) analyzer slice of preprocessed content and the divisor for retained attack-indicator regions during truncation. Does NOT bound the regex scan window (that is detection_max_body_inspect_bytes).
    detection_max_scan_values detectionMaxScanValues int, 2–100000 (ge=2, le=100000) 512 Max individual values (query params, header values, JSON keys/leaf values, form fields, multipart parts) scanned per request; each value costs two units (name + value). Beyond the cap, remaining values are not scanned; one-time warning names the client IP.
    detection_max_scan_chars detectionMaxScanChars int, 1024–262144 (ge=1024, le=262144) 65536 Max total characters across every value handed to the pattern engine per request. Beyond the cap: same fail-open + warning as above.
    detection_max_json_depth detectionMaxJsonDepth int, 1–1000 (ge=1, le=1000) 32 Max JSON nesting depth walked structurally. At the cap, the value is serialized to text and scanned as one value (still scanned, bounded by detection_max_content_length); one-time warning.
    detection_preserve_attack_patterns detectionPreserveAttackPatterns bool true Preserve attack patterns during content truncation.
    detection_semantic_threshold detectionSemanticThreshold float, 0.0–1.0 (ge=0.0, le=1.0) 0.7 Semantic attack-detection threshold.
    detection_anomaly_threshold detectionAnomalyThreshold float, 1.0–10.0 (ge=1.0, le=10.0) 3.0 Standard deviations from mean to flag an anomaly.
    detection_threat_score_threshold detectionThreatScoreThreshold float, 0.0–10.0 (ge=0.0, le=10.0) 1.0 Anomaly score required to flag a request as a threat.
    detection_slow_pattern_threshold detectionSlowPatternThreshold float, 0.01–1.0 (ge=0.01, le=1.0) 0.1 Execution time (seconds) to consider a pattern slow.
    detection_monitor_history_size detectionMonitorHistorySize int, 100–10000 (ge=100, le=10000) 1000 Recent metrics kept in history.
    detection_max_tracked_patterns detectionMaxTrackedPatterns int, 100–5000 (ge=100, le=5000) 1000 Max patterns tracked for performance.
    detection_anomaly_emission_cooldown detectionAnomalyEmissionCooldown float, 1.0–3600.0 (ge=1.0, le=3600.0) 60.0 Min seconds between anomaly events for the same pattern.
    detection_min_samples_for_anomaly detectionMinSamplesForAnomaly int, 10–1000 (ge=10, le=1000) 30 Samples recorded before anomaly detection engages.
    detection_compiler_timeout detectionCompilerTimeout float, 0.1–10.0 (ge=0.1, le=10.0) 2.0 Timeout for pattern compilation and matching (seconds).
    ## Behavioral rules
    Field Kotlin property Type Default Effect
    global_behavior_rules globalBehaviorRules rule list [] Behavior rules applied to every route in addition to decorator rules (section 12).
    behavior_scan_response_body behaviorScanResponseBody bool false When false, no response body is ever read for pattern matching and non-status: return_pattern rules can never match; construction rejects such a rule instead of accepting a silent no-op.
    behavior_max_response_body_inspect_bytes behaviorMaxResponseBodyInspectBytes int, 1024–10485760 (ge=1024, le=10485760) 262144 Max bytes of response body retained for return_pattern inspection. Bounds what is retained, not what the app produces: the reader must deliver the full body afterward (section 01.4).
    body_read_timeout bodyReadTimeout float, > 0, <= 30.0 (gt=0.0, le=30.0) 3.0 Seconds to wait for an adapter's body read (request-detection read and response-behavior read) before treating the body as unavailable (fail-closed, same as an adapter raising).
    sync_body_read_max_concurrent syncBodyReadMaxConcurrent int, 1–10000 (ge=1, le=10000) 64 Max concurrent blocked synchronous body reads before further attempts give up and log exhaustion. Applies to sync-only deployments.

    Field Kotlin property Type Default Effect
    blocked_user_agents blockedUserAgents str list [] User-agent patterns to block. Each pattern MUST pass the pattern-safety (ReDoS) validator; unsafe patterns: rejected.
    ## HTTPS / passive / failure policy
    Field Kotlin property Type Default Effect
    enforce_https enforceHttps bool false Redirect HTTP requests to HTTPS.
    passive_mode passiveMode bool false Log-only mode: no request is ever blocked; violations are logged/flagged only.
    fail_secure failSecure bool true On an unexpected exception in any check: true = block with 500 (check bugs surface); false = log and fall through (fail-open, staging diagnostics only).
    route_resolution_strict routeResolutionStrict bool false Block (500) when the adapter cannot resolve the route. False lets unrouted/undecorated requests through with global checks only.
    exclude_paths excludePaths str list ["/docs", "/redoc", "/openapi.json", "/openapi.yaml", "/favicon.ico", "/static"] Paths excluded from security checks. Each entry MUST normalize (reject malformed percent-encoding/invalid UTF-8); an entry that normalizes to / is rejected unless it is the literal /, which is accepted with a warning (excludes the whole application).

    Registry fields beyond the spec 02 tables

    These fields exist in the reference field table and the JVM registry but have no row in the spec 02 field semantics tables. Their effect text here is verified against the reference's field descriptions (guard_core/_security_config_fields.py).

    Field Kotlin property Type Default Effect
    detection_binary_min_run_length detectionBinaryMinRunLength int (ge=4, le=1024) 16 Minimum length a consecutive printable-character run inside a binary-dense multipart file-part payload must reach before that run is handed to the pattern scan. Text uploads and short or mostly-text payloads never reach the binary-density ratio and keep their full scan, and whole-body fallback scans are never island-reduced, so raw-body signature coverage stays intact.
    detection_pattern_validation_cache_path detectionPatternValidationCachePath str or none None Optional file path for a disk-backed pattern-validation cache. When set, the empirical cost-verdict outcome of pattern-safety validation is cached keyed by pattern, flags, and engine version, so a process boot reuses prior certifications instead of re-timing every custom pattern; the cheap deterministic layers always re-run. Cache entries from a different engine version are ignored and overwritten. Leave unset (the default) to keep every validation fully empirical.
    exempt_ips exemptIps str list (IP/CIDR) () IP addresses or CIDR ranges that skip rate limiting and the user-agent and cloud-provider checks. Not restrictive: every other IP is checked as usual. The blacklist, dynamic IP bans, per-route IP rules and penetration detection still apply to listed IPs.

    Assignment-time revalidation: the fields flagged in the registry (list at ConfigFieldRegistry.kt, revalidatedOnAssignment) re-run their validators on every mutation after construction, mirroring _FIELD_REVALIDATORS in the reference.
