    W4a Pipeline Parity (guard-core-jvm)

    Wave gate: the 17 pipeline checks in the reference's fixed order plus the core support modules, gated by the vendored pipeline conformance suites (35 cases) in conformance/guard-core-spec-4.1.0/cases/. Result: 35/35 GREEN (PipelineConformanceTest.pipelineSuitesMatchCorpus, no xfails), plus a 32-test core unit surface. The runner is the JVM port of specs/fixtures/tools/pipeline_harness.py (guard-core-conformance/src/main/kotlin/com/guardcore/conformance/PipelineHarness.kt), driving the real fixed-order pipeline and the real response factory in-process over harness stubs, comparing per the index.json pipeline_records rule (only the keys present in each expected record; the recording bus observes (event_type, action_taken) pairs exactly like the reference harness).

    Semantics pinned during the port

    • Escalation checks read request.state attributes through the same names python uses (route_config, client_ip, is_whitelisted, is_exempt, guard_exclusion_scoped, _guard_block_stash, _guard_detection_result_cache); the state bag is RequestState.getAttr/setAttr (protocols/RequestProtocol.kt).
    • pipeline.execute stamps _guard_pipeline_start with the monotonic clock and AgentEvents.getPipelineResponseTime reads it (agent_events.py:29 analog).
    • The pipeline rebuild contract (pipeline.py:56-81): config revision + watched container sizes (block_cloud_providers, blocked_user_agents, endpoint_rate_limits = factory.py:50-54) + route-config revision token.
    • check_route_ip_access (helpers.py:219) catches the invalid-IP ValueError as ConfigValidationError (the port's ValueError class); unknown identity with a whitelist configured denies (helpers.py:222-223).
    • Suspicious-count increments run under a lock with the 10,000-IP LRU bound (helpers.py:27, :352-372).
    • The harness stubs mirror pipeline_harness.py exactly: _CaseInsensitiveHeaders (:352) is the JVM CaseInsensitiveHeaders; create_harness_error_response (:295) applies the security headers through the real manager; the rate-limit singleton resets per case (:443-457).
