    W2 Detection Engine Parity (guard-core-jvm)

    Wave 2 ports the detection engine: the regex compiler, semantic analyzer, preprocessor, monitor, the full _redos_* static-safety chain, and the SusPatterns pattern tables, into guard-core-engine (kotlin-stdlib only, no frameworks), proven by the corpus detect suites going green under a fail-closed pattern translation ledger.

    Regex compatibility layer (new surface: JVM analog of CPython re/sre)

    python kotlin notes
    (CPython re._parser grammar) py/PyReParser.kt python-grammar fail-closed parser producing the sre AST: ReParseError carries the reference's message classes ("unbalanced parenthesis", "multiple repeat", "nothing to repeat", "invalid group reference N", "redefinition of group name", "global flags not at the start", "unknown extension ?>", nesting-depth cap 20). Atomic groups and possessive quantifiers reject fail-closed (python 3.10 oracle).
    (CPython re._compile + stdlib flags) py/PyRe.kt translateSource (\Z->\z, (?P<->(?<, (?P=->\k, \g->\n, {,n}->{0,n}, python-literal { escaped, (?-i:...) hoisted to scoped positive flags with the CI flag re-applied per segment); flag map: IGNORECASE->CASE_INSENSITIVE
    (CPython ast.parse(mode="eval")) py/PyAst.kt python-expression validator for SemanticAnalyzer._check_ast_parsing_risk: recursive-descent over the eval-mode grammar (lambda, conditional, boolean/comparison/arithmetic, displays, comprehensions, calls, subscripts, f-strings); assignments/statements reject.
    (thread with large stack) py/RegexWorkers.kt shared_regex_executor analog (compiler.py:20-38, 4 workers). The pool carries 512 MiB stacks: java.util.regex recurses per group-repetition iteration, and the corpus's 256 KiB workloads drive ~256k nested frames through the table's negated-newline-star scans. detect() and reachProbeCostVerdict each take one worker hop; matches inside run inline.

    Idiom mappings (syntax, not substitutes)

    1. asyncio -> blocking engine + worker hop: python's async detect and the shared regex executor map to a synchronous detect() executed on one 512 MiB-stack scan-pool worker. Coroutine bridges land in the facade (W4) per the work order's unasync ruling.
    2. killable subprocess -> hard deadline: the reference times probes and verifies strays in killable subprocesses; the JVM analog is the DeadlineCharSequence abort (PyRe.DeadlineExceededException carries the reference's TimeoutError semantics and the reason strings name the same classes: "killable-subprocess timeout" texts kept verbatim for ledger comparability).
    3. sre internals -> PyReParser/PyAst: python's re._parser grammar and ast.parse(mode= "eval") are CPython-internal; the JVM ports reproduce the accept/reject oracle fail-closed (ReParseError message classes verbatim; PyAst = eval-mode expression grammar).
    4. pickle._Unpickler -> opcode table: the blocked-resolution exceptions map to explicit raises in the modeled dispatch; a raise means "not a provable opcode stream" exactly as the reference's exception-to-False conversions.
