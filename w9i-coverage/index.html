    Byte-exact fixes (25 and 26 of the campaign)

    1. PyJsonLike.parseValue (BehaviorResponsePattern.kt): JsonNull IS a JsonPrimitive, so the is JsonPrimitive branch shadowed the JsonNull arm - a null leaf rendered as the string "null" (python json.loads yields None), and a null leaf crashed the pattern comparison instead of comparing str(None) = "none". Fixed byte-exact against python (the null branch first; the comparison and the array-match render None as "none"), regression test in HandlersW9iTailsTest.
    2. PyJsonDumps.render (PyJsonDumps.kt): the compact selector was passed as the ensure_ascii flag, inverting both documented renderers - dumps (json.dumps, ensure_ascii=True) kept non-ASCII as UTF-8 and dumpsCompact (pydantic model_dump_json) escaped it. Fixed to the inverse; the W9h dumps test was pinning the inverted behavior and is corrected to the reference. Regression tests in HandlersW9iTailsTest (dumps escapes, dumpsCompact keeps UTF-8).

    Dead code and dead defaults removed (main sources, with reasons)

    1. SusPatternsManager.removePattern: the compiledPatterns size-skew guard was an addition over python's unconditional del (python remove_pattern keeps the lists in lockstep; removeAt mirrors python's IndexError-on-skew exactly). Removed.
    2. SusPatternsManager.checkUrlDecodedViewPatterns: the recompute branch was unreachable by types - preprocessContent always computes the decoded view alongside the processed content, so precomputedDecoded is non-null and the url-decoded view re-derives from it. Removed.
    3. HandlerInitializer.initializeDynamicRuleManager: the sink-only adapter hardwired getDynamicRules() to null, so no rule flow could ever dispatch sendEvent on it and its body was unreachable. Merged into one behavior-identical adapter over whichever telemetry surface is wired.
    4. RateLimitCheck.applyRateLimitCheck: the endpointPath parameter default generated a never-executed default synthetic (every call site passes the path explicitly). Removed the default.
