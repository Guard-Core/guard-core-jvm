# AGENTS.md
Guidance for AI agents (including Claude Code) working in this repository.

## Project Overview

guard-core-jvm is the Kotlin/JVM engine library of the guard-core API security
ecosystem. It is a library, not an application: there is no main class and
nothing to run. Gradle multi-module workspace (Kotlin DSL), group
`com.guard-core`, version `4.4.1`, JVM toolchain 17.

Module layout:

- `guard-core-engine/` - framework-free engine module. Dependency-free by
  contract: kotlin-stdlib only, no coroutines, no redis, no frameworks, ever.
- `guard-core/` - published facade; depends on the engine and
  kotlinx-coroutines-core.
- `guard-core-conformance/` - corpus runner (unpublished); replays the vendored
  spec 4.1.0 corpus against the engine.
- `guard-core-benchmark/` - JMH benchmarks (unpublished).

The reference implementation is the Python guard-core engine: expected values
in the conformance corpus were generated by running the reference engine and
must never be hand-written. Behavior is kept compatible across ports via the
shared corpus and the comparison contract in `cases/index.json`.

## Boundary Rules

- MUST NOT add dependencies to `guard-core-engine/` beyond kotlin-stdlib.
  Coroutines, redis clients, and framework types belong in the facade or in
  adapter repositories (framework adapters contain no security logic).
- MUST NOT hand-edit anything under `conformance/guard-core-spec-4.1.0/cases/`.
  The corpus is vendored byte-identical from the guard-core specs/fixtures,
  generated by the reference engine, never hand-written. Refresh it by
  re-vendoring with `cp -p` and verifying with `diff -r`; never pretty-print,
  re-order, or re-encode the JSON.
- MUST NOT change detect verdicts, scores, or result shapes without
  regenerating the corpus from the reference engine.
- MUST NOT push to `master` (protected), and MUST NOT create tags or releases
  outside the release process.

## Quality Gates

```bash
./gradlew build --no-daemon   # full gate: compile + tests + detekt + ktfmt check
./gradlew spotlessApply       # auto-format with ktfmt
./gradlew detekt              # static analysis only
```

`./gradlew build` must be green before every push (never push red). CI runs
the same command with JDK 17 plus CodeQL. JaCoCo is applied but has no coverage
gate yet; that lands with real engine code in W1+.

## Versioning

Mirror-lockstep: guard-core-jvm releases carry the same version number as the
guard-core engine release they mirror (currently 4.4.1). The conformance corpus
records the exact engine commit it was generated at; when the engine moves,
re-vendor the corpus and bump the workspace version together.
