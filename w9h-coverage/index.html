    Dead code and dead defaults removed (main sources, with reasons)

    1. HandlerInitializer.compositeSinkAgentProtocol: a PRIVATE adapter with zero call sites in the repo (the composite is passed as the telemetry handler through initializeAgentForHandlers/compositeSink instead); the W9e-era test named for it never invoked it. Deleted.
    2. SecurityCheckPipeline.logExtra: a PRIVATE structured-log builder with zero call sites (python pipeline.py:83's _log_extra has no ported caller). Deleted.
    3. CloudManager.scheduleRefresh: removed the try/catch around scope.launch { runRefresh() } - the scope is constructed three lines above and its job cannot reject, so launch cannot throw there.
    4. Dead Kotlin parameter defaults with no omitting call site (each generated a never-executed default-arg synthetic): IpSecurityCheck checkGlobalIpRestrictions routeConfig, CloudManager refreshProvidersViaRedisHandler ttl, RepeatAlphabet collectAlphabetAtoms repeated.
